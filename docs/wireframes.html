4. Category page (e.g. /asia, /land)

Same header and red menu as the homepage. Posts are newest first and grouped by day. Each day starts with a plain text date heading (e.g. "Today · Tuesday, 3 November 2026") that stays in view while you scroll that day's stories, so readers always know when each story ran. Each story also shows its own time.
